# FOSSEE Workshops 

A modern, responsive SaaS-style web application for managing and exploring FOSSEE workshops.  
Built with React, Vite, Tailwind CSS, and Framer Motion — inspired by modern UI platforms like Lovable.

---

## ✨ Features

- 🔥 Modern SaaS UI (Glassmorphism + Gradient Design)
- 🎯 Fully Responsive Design
- 🔐 Authentication System (Login/Register/Forgot Password)
- 📊 Dashboard & Statistics
- 📚 Workshop Listing & Detail Pages
- 🧠 Custom Hooks & Context API
- ⚡ Smooth Animations (Framer Motion)
- 🎨 Reusable UI Components
- 🚀 Fast build with Vite

---

## 🛠️ Tech Stack

- React (Vite)
- Tailwind CSS
- Framer Motion
- React Router
- Context API
- Custom Hooks

## ⚙️ Installation
git clone https://github.com/HemaRamachandran28/fossee-workshop.git
cd fossee-workshop
npm install
npm run dev
